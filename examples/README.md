# Examples

This directory contains example code demonstrating features and patterns used in lazy-pandas.

## Files

- `example_feature.py` - Example class demonstrating the use of `ContributionAcceptedError` for features that are not yet implemented but welcome contributions.
- `test_example_feature.py` - Example tests showing how to use the `@skip_on_contribution_error` decorator to automatically skip tests for unimplemented features.

These examples are primarily for documentation and development purposes, showing contributors how to properly mark and test features that are open for contribution.
